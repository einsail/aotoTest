API Testing Framework

http://localhost:8080

Environment

Base URL: http://localhost:8080

Default timeout: 3000 ms

Active profile is determined by the test.env property.

Included Layers

  • config - typed configuration & environment resolution
  • client - reusable RestAssured clients
  • model - DTOs for API payloads
  • utils - specs, logging, hooks
  • test - TestNG suites powered by Spring context

Sample Endpoints

  • /api/health - health check
  • /api/users - demo user list

Use mvn test -Dtest.env=dev to exercise the TestNG suite with RestAssured.
